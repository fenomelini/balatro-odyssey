## 🌌 O que é o Balatro Odyssey?

Balatro Odyssey não é apenas um pacote de conteúdo — é uma **revisão completa**. Desenvolvido para jogadores que dominaram o jogo base e querem uma profundidade estratégica sem precedentes, o Odyssey adiciona um cosmos inteiro de novas mecânicas, condições de vitória e interações sobre a fundação do Balatro.

O mod pode funcionar em dois modos:
- **Conversão Total** (padrão): Apenas o conteúdo do Odyssey aparece nas lojas e pools. Um jogo alternativo verdadeiro.
- **Junto com o Vanilla**: O conteúdo clássico do Balatro coexiste com todas as adições do Odyssey.

O novo objetivo de vitória é o **Ante 100** — o Odyssey Final.

## 🃏 Os 22 Grupos de Curingas

Todos os 1.000 Curingas estão organizados em famílias temáticas. Cartas do mesmo grupo compartilham mecânicas e têm sinergia entre si.

| Grupo | Tema |
|---|---|
| **Singularidade** | Manipulação isolada de cartas; mecânicas de "Buraco Negro" que consomem recursos por poder enorme |
| **Quântico** | Efeitos de sobreposição — cartas existem em múltiplos estados simultaneamente; pontuação baseada em incerteza |
| **Temporal** | Controle do tempo de run; efeitos de retrigger de rodadas passadas; manipulação de Antes |
| **Dimensões** | Interações dimensionais cruzadas; Curingas que interagem com cartas em diferentes áreas |
| **Corrupção** | Cartas de alto risco que podem corromper seu baralho em troca de poder extremo |
| **Caos** | Efeitos totalmente aleatórios; mecânicas de entropia; o inesperado é a mecânica |
| **Economia** | Geração de dinheiro, manipulação de loja, sinergias de vender/comprar |
| **Transformações** | Cartas que alteram permanentemente outros Curingas, melhorias ou naipes |
| **Sorte e Probabilidade** | Manipulação de numeradores e denominadores de probabilidade; sinergias de apostas |
| **Posicionamento** | Pontuação dependente do slot do Curinga e da posição na mão |
| **Mão e Descarte** | Composição da mão, quantidade de mãos restantes, efeitos baseados em descarte |
| **Elemental** | Espíritos de Fogo, Água, Terra e Ar; sinergias de tipo elemental |
| **Tribal** | Sinergias de figuras, naipes e grupos por rank |
| **Social** | Curingas que interagem entre si; efeitos de vizinho; escalonamento por contagem |
| **Condições** | Pontuação condicional que recompensa estilos de jogo específicos |
| **Tempo** | Velocidade de jogo em tempo real; duração de rodada; mecânicas de relógio |
| **Paradoxos** | Efeitos autocontraditórios; Curingas cujas regras quebram suas próprias condições |
| **Celestial** | Tema de estrelas e cosmos; mecânicas de corpos planetários |
| **Anomalia** | Adjacente ao Glitch; comportamento indefinido como recurso |
| **Glitch** | Efeitos de UI corrompida; valores que não deveriam ser possíveis |
| **Profissões** | Arquétipos de RPG aplicados à estratégia |
| **Final** | Cartas de fim de jogo balanceadas para o Ante 100; as mais raras e poderosas |

## 🎯 O Gauntlet — Estrutura de Antes

Balatro Odyssey redefine a progressão da run:

- **Antes 1–8** → Boss Blinds Vanilla (aquecimento familiar)
- **Antes 9–99** → 100 novos Boss Blinds do Odyssey com habilidades cósmicas únicas
- **Ante 100** → O Odyssey Final (condição de vitória)

Cada novo Boss Blind tem seu próprio tema, mecânica única de debuff e entrada de lore.

## 🚀 Instalação

### Pré-requisitos

| Dependência | Onde obter |
|---|---|
| **Balatro** | [Steam](https://store.steampowered.com/app/2379780/Balatro/) |
| **Steamodded** | [GitHub](https://github.com/Steamodded/smods) |
| **Lovely Injector** | [GitHub](https://github.com/WilsontheWolf/lovely-injector) |

### Passo a passo

**1. Baixe o mod**

Acesse a [página de Releases](https://github.com/fenomelini/balatro-odyssey/releases) e baixe o `BalatroOdyssey.zip` mais recente.

**2. Encontre sua pasta Mods**

| SO | Caminho |
|---|---|
| Windows | `%AppData%\Balatro\Mods` |
| Linux | `~/.local/share/Balatro/Mods` |
| macOS | `~/Library/Application Support/Balatro/Mods` |

**3. Instale**

Extraia o zip para que a estrutura fique assim:
```
Mods/
└── BalatroOdyssey/
    ├── BalatroOdyssey.lua
    ├── manifest.json
    └── assets/
```

**4. Jogue**

Inicie o Balatro e confirme que **Balatro Odyssey** aparece habilitado no menu de Mods.
