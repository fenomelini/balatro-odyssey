## 🌌 What Is Balatro Odyssey?

Balatro Odyssey is not just a content pack — it is a **complete overhaul**. Designed for players who have mastered the base game and hunger for unprecedented strategic depth, Odyssey adds an entire cosmos of new mechanics, win conditions, and interactions on top of Balatro's foundation.

The mod can run in two modes:
- **Total Conversion** (default): Only Odyssey content appears in shops and pools. A true alternative game.
- **Alongside Vanilla**: Classic Balatro content co-exists with all Odyssey additions.

The new victory target is **Ante 100** — the Final Odyssey.

## 🃏 The 22 Joker Groups

All 1,000 Jokers are organized into thematic families. Cards within the same group share mechanics and synergize with each other.

| Group | Theme |
|---|---|
| **Singularity** | Isolated card manipulation; "Black Hole" mechanics that consume resources for massive power |
| **Quantum** | Superposition effects — cards exist in multiple states simultaneously; uncertainty-based scoring |
| **Temporal** | Run-time control; retrigger effects from past rounds; Ante manipulation |
| **Dimensions** | Cross-dimensional interactions; Jokers that interact with cards across different areas |
| **Corruption** | High-risk cards that can corrupt your deck in exchange for extreme power |
| **Chaos** | Fully random effects; entropy mechanics; the unexpected is the mechanic |
| **Economy** | Money generation, shop manipulation, sell/buy synergies |
| **Transformations** | Cards that permanently change other Jokers, enhancements, or suits |
| **Luck & Probability** | Manipulate probability numerators and denominators; gambling synergies |
| **Positioning** | Joker-slot and hand-position dependent scoring |
| **Hand & Discard** | Hand composition, number of hands remaining, discard-based effects |
| **Elemental** | Fire, Water, Earth, Air Spirits; elemental type synergies |
| **Tribal** | Face cards, suits, and rank-tribe synergies |
| **Social** | Jokers that interact with each other; neighbor effects; count-based scaling |
| **Conditions** | Conditional scoring that rewards specific playstyles or meeting criteria |
| **Time** | Real-time play speed; round duration; clock-based mechanics |
| **Paradoxes** | Self-contradictory effects; Jokers whose rules break their own conditions |
| **Celestial** | Star and cosmos themed; planetary body mechanics |
| **Anomaly** | Glitch-adjacent; undefined behavior as a feature |
| **Glitch** | Corrupted UI effects; values that shouldn't be possible |
| **Professions** | Role-playing archetypes applied to strategy |
| **Final** | End-game cards balanced for Ante 100; the rarest and most powerful |

## 🎯 The Gauntlet — Ante Structure

Balatro Odyssey redefines the run progression:

- **Antes 1–8** → Vanilla Boss Blinds (familiar warmup)
- **Antes 9–99** → 100 brand-new Odyssey Boss Blinds with unique cosmic abilities
- **Ante 100** → The Final Odyssey (win condition)

Each new Boss Blind has its own theme, unique debuff mechanic, and lore entry.

## 🚀 Installation

### Prerequisites

| Dependency | Where to get |
|---|---|
| **Balatro** | [Steam](https://store.steampowered.com/app/2379780/Balatro/) |
| **Steamodded** | [GitHub](https://github.com/Steamodded/smods) |
| **Lovely Injector** | [GitHub](https://github.com/WilsontheWolf/lovely-injector) |

### Steps

**1. Download the mod**

Go to the [Releases page](https://github.com/fenomelini/balatro-odyssey/releases) and download the latest `BalatroOdyssey.zip`.

**2. Find your Mods folder**

| OS | Path |
|---|---|
| Windows | `%AppData%\Balatro\Mods` |
| Linux | `~/.local/share/Balatro/Mods` |
| macOS | `~/Library/Application Support/Balatro/Mods` |

**3. Install**

Extract the zip so you have:
```
Mods/
└── BalatroOdyssey/
    ├── BalatroOdyssey.lua
    ├── manifest.json
    └── assets/
```

**4. Launch**

Start Balatro and confirm **Balatro Odyssey** is listed and enabled in the Mods menu.
